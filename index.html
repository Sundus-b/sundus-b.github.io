Data Analytics

Descriptive Analysis of the 2019 Stack Overflow Developer Survey

IBM Data Analytics Final Project · July 2022

An end-to-end analysis of a subset of Stack Overflow's 2019 Developer Survey, examining technology usage trends and developer demographics. The dataset was cleaned and analyzed in Python and SQL, then delivered as a formal report and an interactive Cognos dashboard.

11,398

3

Approach: cleaned and normalized the raw dataset in Python (pandas) and SQL — including duplicate removal and imputation — then conducted exploratory analysis and visualization in Python and Cognos Analytics.

  • JavaScript, HTML/CSS, and SQL were the most-used technologies in 2019 and projected to stay dominant, with rising interest in Python and TypeScript
  • PostgreSQL and MongoDB were gaining ground on traditional SQL databases, pointing to growing NoSQL adoption
  • Compensation and age were positively correlated, and median compensation was slightly higher for women than men in this sample
  • A significant gender representation gap persisted in the developer population (93.5% male vs. 6.5% female)
